# Repository instructions

The app is in docs/quietneeds-starter. Before app work, read its AGENTS.md, STATE.md and referenced execution/design/architecture/checkpoint files.

Use task branches and reviewable commits. Inspect staged paths and private configuration before each commit. Keep .env.local, debug tokens, node_modules, caches, build output and real participant data out of Git. Do not make direct implementation commits to main. Record actual check results; never equate passing CI with a completed product phase.

See CONTRIBUTING.md for the repository workflow.
